01

Choose Actual Size

In the print dialog, pick “Actual Size” or 100%, not “Fit to Page”. Fitting shrinks the sheet, which shifts every label off its sticker.

02

Test on plain paper

Print one page on plain paper and hold it against a label sheet in front of a window. If the outlines match, load the stickers.

03

Feed the right way up

Check which side your printer prints on, and load the stickers top edge first.

How to label moving boxes

Six habits that make unpacking easy.

Number every box

A number is easier to call out than “the kitchen one with the tape.” Keep a matching line on the inventory checklist.

Label two sides and the top

Stacked boxes hide their tops. A label on a side and the top means you can read it however it's stacked.

Color-code rooms

Fill each label's color square with a marker: blue for the kitchen, green for the garage. Movers can sort by color without reading.

List what you'll go looking for

Skip “misc.” Write the things you'll actually need later: chargers, the coffee maker, passports.

Pack an Open First box

Sheets, towels, toilet paper, tools, phone chargers, and snacks. Tick Open First so it's unpacked on night one.

Tick Fragile and This Side Up

Use them sparingly. If everything is marked fragile, movers stop noticing the label.

Good to know

Questions, answered.

Which Avery labels fit these moving box labels?

The 6-per-sheet file fits Avery 5164 and 8164 (4″ × 3⅓″) shipping labels. The 4-per-sheet file fits Avery 5168 and 8168 (3½″ × 5″). Other brands sold as compatible with those numbers work too.

Can I print moving labels on plain paper?

Yes. The Letter and A4 versions have dashed cut lines. Cut them out and cover the whole label with clear packing tape so it survives the move.

Can I type on the labels before printing?

Yes. Every PDF is fillable. Open it in Preview, Acrobat Reader, or your browser, type the room, box number, and contents, tick any boxes, then print.

Why are my labels not lining up with the stickers?

Print at Actual Size or 100% scale. “Fit to Page” shrinks the sheet slightly, which shifts each label off its sticker. Test on plain paper first and hold it against a label sheet to check the alignment.
