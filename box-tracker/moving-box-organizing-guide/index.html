The four rules

A small system beats a perfect one.

Use the same four pieces of information on every box. Consistency is what makes the list useful when the room is full of cardboard.

1

One number

Number boxes in one sequence for the whole move, rather than starting over in each room.

2

One destination

Write the room in the new home so helpers know where the box should be unloaded.

3

Useful contents

List the few things you may need to find before the box is fully unpacked.

4. Put the label where it stays visible

Label the top and at least one side. A top label helps while carrying; a side label remains readable in a stack. Use Fragile, This Side Up, and Open First only when they are actually true.

On moving day, count instead of guessing

Check each box number onto the truck and off again. If a number is missing or a box is damaged, investigate while the movers are still there. The PDF includes six fillable rows; for a larger move, use the full moving inventory list.
